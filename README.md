## Technologies utilisées
- **HTML5 / CSS3** — Structure et mise en forme, Flexbox, responsive design
- **jQuery** — Animations, timeline interactive, texte animé, effets de survol
- **ReactJS** — Composants dynamiques de ProjectCard, ProjectsList, ContactForm
- **GitHub Pages** — Dépôt public, URL accessible, README documenté

## Structure du projet
rania1289.github.io/
    index.html              → Structure de la page
    style.css               → Design et mise en forme
    jquery-script.js        → Animations et interactivité
    photo.png               → Photo de profil
    README.md               → Documentation du projet
    
    react-components/
        app.js          → Composants React

## Fonctionnalités
- Navbar verticale fixe avec scroll doux
- Texte animé qui s'écrit lettre par lettre
- Barres de compétences animées au scroll
- Timeline de formation interactive au clic
- Cartes projets via composant React
- Formulaire de contact avec validation
